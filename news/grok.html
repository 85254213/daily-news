  1. Grok Bot 正在推进 Token 效率与行为改进

  2. Grok Bot 两起服务事件均已恢复

    事件日期：2026-11-06 至 11-07

    官方状态记录显示，部分地区的 Computer Use 故障约 13 分钟后恢复；当天稍后另一次 Grok Bot 服务降级也已解决。公开记录没有披露根因，不把它扩大为所有 Grok 产品的全面宕机。

    来源：xAI 官方状态页；DigIntoAI 事件核验；ST Studio 状态记录汇总

  3. xAI 为部分 Grok API 文本输出启用隐形水印

    生效日期：2026-11-07

    xAI 文档说明，部分 Grok 模型经 Responses API 与 Chat Completions API 生成的文本默认带统计水印，并通过 x-watermark 响应头提示；符合条件的组织管理员可按规定申请关闭。

    来源：xAI 官方开发文档；Metarix 技术解读

  4. Grok Bot 官方宣布新增电话拨打能力

    发布日期：2026-11-04

    Grok Bot 展示代用户拨打电话、生成实时文字记录并允许用户接管通话的流程。现有信息主要指向美国号码，实际地区、语言及账户开放范围仍以产品端为准。

    来源：Grok Bot 官方 X 动态；FindSkill 独立使用与安全核验

  5. Grok Bot 推出新的购物体验

    官方展示：2026-11-03（北京时间 2026-11-04）

    官方演示显示 Bot 可查找优惠、比较商品并追踪订单。购物卡片、Shop Pay、下单审批和物流状态等基础能力可在官方更新日志中核验，但不代表每个地区或账户均已开放。

    来源：Grok Bot 官方 X 动态；Grok Bot 官方更新日志

  6. xAI 发布团队共享的 Data Bot

    发布日期：2026-11-02

    Data Bot 是由数据科学团队维护技能的 Team Bot，可查询数据仓库、运行分析、回答指标与实验问题，并在 Slack 或报告中按团队规范输出结果。

    来源：xAI 官方公告

  7. 旧版 Grok Imagine 图像质量模型标识完成迁移

    生效日期：2026-11-02

    grok-imagine-image-quality 与 grok-imagine-image-pro 的请求现转到 grok-imagine-image-2.0 的低质量档；请求和响应结构保持不变，官方称单张价格下降。
