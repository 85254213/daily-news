  1. xAI 展示由团队共同维护的 Data Bot

    发布日期：2026-11-02

    xAI 介绍了 Grok Bot 中的团队智能体 Data Bot：由数据科学团队维护共享技能，可查询数据仓库、分析指标和实验，并在 Slack 中回答问题或定时发布报告。官方称其上一周约承接了 70 小时原本会落到数据团队的工作。

    来源：xAI 官方公告

  2. Grok Bot 使用额度争议：马斯克称服务成本相对收入“不可持续”

    报道日期：2026-11-02；相关回应日期：2026-11-01

    多家媒体报道部分订阅用户的周额度比往常更快耗尽。马斯克确认 Grok Bot 的服务成本相对收入过高，但尚未公布成本数字、额度调整范围或后续恢复方案。

    来源：TechCrunch；Forbes

  3. Grok Bot 新增购物卡片、订单追踪与订阅管理模板

    独立报道：2026-11-02；版本发布日期：2026-10-27（v0.78.1）

    新版本把商品照片、评分、价格和商店集中为卡片，可在用户批准后通过 Shop Pay 发起订单并追踪物流；同时加入试用到期提醒、取消未使用订阅和续费价格监控。团队管理员还可为 Team Bot 配置专用登录信息。

    来源：Grok Bot 官方更新日志；Magica 独立报道

  4. 旧版 Grok Imagine 图像质量模型标识完成迁移

    生效日期：2026-11-02

    `grok-imagine-image-quality` 标识已退役，请求会转到 `grok-imagine-image-2.0` 的低质量设置；请求和响应结构不变，官方称单张价格更低。`grok-imagine-image` 1.0 不受影响。

    来源：xAI 官方迁移指南；xAI 官方发布说明

  5. Grok API 将默认给文本输出加入不可见统计水印

    官方文档更新：2026-10-31；计划生效：2026-11-07

    水印覆盖 Grok 4.7、4.6、4.5、4.3 和 Grok 4.20 系列的普通文本、结构化输出及工具调用参数，并通过 `x-watermark` 响应头标识。团队管理员只有在确认适用法律例外时才能按模型选择退出。

    来源：xAI 官方文档；Crypto Briefing 独立报道

  6. Grok API 增加按请求设置的内容审核规则

    独立报道：2026-10-28；官方发布说明：2026-10-27

    开发者可在 Chat Completions 或 Responses 请求中加入 `guidelines`，指定 Grok 对成人内容、暴力和粗俗语言等类别采取拒绝策略。该控制按请求生效，并不等同于平台统一修改所有模型的默认政策。

    来源：xAI 官方文档；Advance Intelligence 独立报道

  7. SpaceXSI 推出面向 Grok 企业落地的合作伙伴网络

    独立报道：2026-10-28；官方公告：2026-10-22

    该网络分为帮助企业部署 Grok 的转型伙伴，以及开发插件和产品集成的市场伙伴。官方称早期阶段已有 130 多家公司参与，并为合作方提供培训、工具和支持。

    来源：xAI 官方公告；CRN 独立报道

  8. xAI 公布销售团队的三个共享 Grok Bot 用例

    发布日期：2026-10-27

    Account Intel Bot、Quote Bot 与 Deal Bot 分别承担客户研究及 Salesforce 更新、报价与订单表单生成、非标准条款审核。关键报价选择、例外处理和最终发送仍由人员判断或批准。

    来源：xAI 官方案例
