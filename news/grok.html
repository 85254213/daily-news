  1. Grok 4.8 完成预训练，计划向部分 Bot 用户软启动

    公开回应日期：2026-11-10

  2. Grok Bot 重置每周用量，效率修复仍在推进

    重置公告：2026-11-10；修复回应：2026-11-08 至 11-09

    官方账号据报为所有用户重置了每周用量，团队同时继续处理 Token 消耗和任务行为问题。重置额度不等于底层执行问题已解决，长期限额规则和实际改进幅度仍未公布。

    来源：Tao Media 独立报道；BIBIBI 二次核验与风险说明

  3. Grok Bot 团队集中展示通话、购物、Team Bot 与安全更新

    展示日期：2026-11-10

    产品负责人 Matt Palmer 演示电话代办、促销码购物、礼物规划、Team Bot 角色与分析面板，以及网页隐藏指令告警等能力；通话仍有地区限制，购买和高风险操作继续需要用户审批。

    来源：WebProNews 功能梳理与演示引用；Grok Bot 官方更新日志

  4. xAI 为部分 Grok API 文本输出启用隐形水印

    生效日期：2026-11-07

    xAI 文档说明，部分 Grok 模型经 Responses API 与 Chat Completions API 生成的文本默认带统计水印，并通过 x-watermark 响应头提示；符合条件的组织管理员可按规定申请关闭。

    来源：xAI 官方开发文档；Metarix 技术解读

  5. Grok Bot 0.79.3 增加共享页主题并修复通话卡片

    发布日期：2026-11-06

    官方更新日志记录了共享页面明暗主题、同一 Slack 工作区成员直接私聊 Team Bot、网页抓取回退和订单持续追踪，并修复无人接听提示、通话转录截断和多项连接状态问题。

    来源：Grok Bot 官方更新日志

    来源：xAI 官方状态页；DigIntoAI 事件核验；ST Studio 状态记录汇总
