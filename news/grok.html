  1. Grok Bot for Mac 接入七项苹果系统能力

    公告及报道日期：2026-11-12

    Grok Bot 官方账号宣布 Mac 端可使用 Messages、Mail、Notes、Reminders、Calendar、Location 与 Contacts。报道确认了接入范围，但尚无独立实测说明各项权限、地区和账户条件。

    来源：9to5Mac（含官方公告原文）

  2. Grok Bot 1.0 正式推出共享团队 Bot、会议参与和主动跟进

    正式公告日期：2026-11-11；官方产品页标注：2026-11-02

    1.0 版把 Team Bot 扩展到 Slack、Microsoft Teams、Google Meet 与 Zoom，可在会议聊天中回答并发送会后摘要，也能识别未完成工作并主动建议跟进。Team Bot 面向 Team、Enterprise，会议能力另覆盖 Ultra；同一发布事件的多篇报道已合并。

    来源：xAI 官方发布；Grok Bot 官方更新日志；Supercharged Daily 独立核验

  3. Gopuff 在 Grok Bot 内上线端到端购物与结账

    发布日期：2026-11-11；独立报道：2026-11-12

    用户连接 Gopuff 后，可在 Grok Bot 对话中浏览本地库存、组建购物车、选择支付方式并确认下单。价格、促销与配送窗口来自 Gopuff 系统；最快15分钟送达和99.5%准确率均为公司口径，实际覆盖取决于地址。

    来源：Gopuff 官方公告；The Philadelphia Inquirer

  4. Grok 4.8 仍处于强化学习与小范围测试阶段

    进展公开日期：2026-11-10；核验更新：2026-11-12

    马斯克称 Grok 4.8 已完成预训练，正运行强化学习，并计划本周向部分 Grok Bot 用户软启动。到本轮检索时，xAI 仍未发布 4.8 的正式模型页、API 型号、价格或基准，因此不把社交平台的“静默上线”说法写成正式发布。

    来源：explainx.ai（11月12日核验更新）；xAI 官方模型目录

  5. xAI 更新 Grok API 水印说明：文本水印默认关闭

    官方文档更新日期：2026-11-11

    最新文档明确，列出的 Grok 文本模型默认不加水印，团队管理员可按模型开启；启用后会覆盖 Responses API 与 Chat Completions API，并可通过 x-watermark 响应头核验。此项修正了此前“默认开启”的旧表述。

    来源：xAI 官方开发文档

  6. Grok Bot 重置每周用量，效率和任务行为修复继续推进

    修复回应与重置日期：2026-11-08 至 11-10

    官方账号为 Grok Bot 用户执行了一次每周用量重置，团队同时继续处理 Token 消耗和任务行为问题。公开信息没有宣布永久提高额度、退款或新的长期限额，因此这是一轮临时重置和修复进展。

    来源：GrokShelf 事件时间线；Tao Media

  7. Grok Bot 与 cursor.com 请求及支付错误事件已解决
