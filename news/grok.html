  1. xAI 为部分 Grok API 文本输出启用隐形水印

    生效日期：2026-11-07

    xAI 文档说明，部分 Grok 模型经 Responses API 与 Chat Completions API 生成的文本将默认带统计水印，并通过 x-watermark 响应头提示；符合条件的组织管理员可申请关闭。

    来源：xAI 官方开发文档；Padzero 技术摘要

  2. Grok Bot 部分地区电脑操作功能短时受影响后恢复

    事件日期：2026-11-06；恢复状态核验：2026-11-07

    状态记录显示 Grok Bot 的 computer use 在少数地区出现中断；随后公开状态监测恢复为正常。官方未在公开记录中说明根因，不对影响范围作额外推断。

    来源：xAI 官方状态页；FrontierTerm 事件记录；OpenUptime 状态监测

  3. Grok Bot 使用额度收紧，服务成本问题再受关注

    报道日期：2026-11-05；相关回应日期：2026-11-01

    部分订阅用户报告额度快速耗尽。马斯克回应称 Grok Bot 的服务成本相对收入不可持续，但 xAI 尚未公布统一的新额度表、成本明细或完整恢复时间表。

    来源：BetaNews 独立报道；TechRadar 独立报道

  4. Grok Bot 官方宣布新增电话拨打能力

    发布日期：2026-11-04

    Grok Bot 展示代用户拨打电话、生成实时文字记录并允许用户接管通话的流程。现有信息主要指向美国号码，实际地区、语言及账户开放范围仍以产品端为准。

    来源：Grok Bot 官方 X 动态；AI Bites 独立摘要

  5. Grok Bot 推出新的购物体验

    发布日期：2026-11-03（北京时间 2026-11-04）

    官方演示显示 Bot 可查找优惠、比较商品并追踪订单。该公告证明功能展示已发布，但不代表每个地区、商店或账户均已开放。

    来源：Grok Bot 官方 X 动态；Grok Bot 官方更新日志

  6. xAI 发布团队共享的 Data Bot

    发布日期：2026-11-02

    Data Bot 由数据科学团队维护共享技能，可查询数据仓库、运行分析、回答指标与实验问题，并按团队习惯在 Slack 或报告中返回结果。

    来源：xAI 官方公告

  7. 旧版 Grok Imagine 图像质量模型标识完成迁移

    生效日期：2026-11-02

    grok-imagine-image-quality 与 grok-imagine-image-pro 的请求现转到 grok-imagine-image-2.0 的低质量档；请求和响应结构保持不变，官方称单张价格下降。

    来源：xAI 官方迁移指南；xAI 官方发布说明
